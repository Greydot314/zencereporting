# Zence AI Insights

Zence 360 – Unified Analytics Workspace with AI Insight Layer

Prompt:
Create a modern, sleek, intuitive prototype for Zence 360, a multi-module analytics platform. Use the reference layout from the uploaded screenshot. The prototype must include the following:

1. Main Dashboard (Home Screen)

Replicate the "My Applications" module layout from the shared screenshot.

Modules to include with clean icons:

Atlas Prime – Complete brand performance analysis

Clickrev – Reviews, ratings & sentiment analytics

Behavioural Analytics – Customer behaviour tracking

Fraud – Fraud detection & risk scoring

Insights – AI-powered insights

KPI Alerts

Segcon

Loyalty Extension

Keep the card-based grid layout with large white cards, light shadows, purple accent design and module names below.

2. AI Insight Screen (Tableau Pulse Style)

Create a dedicated AI Insights layer accessible from top navigation or a floating AI button.

Features to include:
A. AI Weekly & Daily Pulse

A clean dashboard that shows:

“What happened yesterday” (sales, transactions, footfall, conversion, revenue shifts)

“What happened last week”

Highlight anomalies, spikes, dips

Quick business health indicators:

Is the business performing normally?

Which KPIs dropped?

Which segments performed best?

B. Crisp AI Narrative Summaries

Design a section where AI writes:

Short, natural-language insights (like Tableau Pulse / Power BI Copilot)

Examples:

“Revenue dropped 8% yesterday compared to last week due to a fall in store visits.”

“Fraud attempts increased by 14% this week. High-risk cluster detected in store zone 3.”

“Clickrev rating improved to 4.2⭐ driven by positive saree collection reviews.”

C. Drill-Down AI Cards

Each card expands into:

Trend line

Contributing factors

Root cause explanation

Recommended actions

D. Cross-Module AI Intelligence

AI summary should intelligently combine data from:

Atlas → overall business KPIs

Clickrev → reviews & sentiment shifts

Fraud → anomalies, risky patterns

Behavioural Analytics → user journey behaviour

Insights → segment-wise insights

3. Module-Level AI Screen

For each module, create a dedicated AI view.

Example:
Atlas → AI Insight Tab

Performance snapshot

Compare vs last week/month

Significant store/category changes

Auto-detected operational issues

Clickrev → AI Insight Tab

Review trends

Popular products

Sentiment anomalies

Behavioural Analytics → AI Insight Tab

Drop-off funnel insights

Cohort performance

Customer lifecycle shifts

Fraud → AI Insight Tab

Risk score insight

Real-time anomaly signals

Suspicious transaction clusters

4. Visual Style

Maintain Zence’s purple theme

Keep the UI clean, enterprise-grade, and minimal

Use micro-animations for AI cards expanding

Rounded card corners (8–16px)

Subtle gradients for AI sections

Use conversational UI for AI summaries

5. Prototype Deliverables

Home screen with modules (based on screenshot)

Global AI Insights pulse screen

AI insight tab inside each module

Responsive design for desktop
